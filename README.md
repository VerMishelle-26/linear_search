\# Линейный поиск и сложность алгоритмов



Учебный проект по алгоритмам и структурам данных.



\## Что реализовано



1\. \*\*Алгоритм линейного поиска\*\* — функция `linear\_search(arr, target)` возвращает индекс элемента или `-1`.

2\. \*\*Анализ сложности\*\* — временная `O(n)`, пространственная `O(1)`.

3\. \*\*Список из 100 случайных чисел\*\* — поиск нескольких значений с результатами.

4\. \*\*Сравнение скоростей\*\* — для списков размером 10, 100, 1000, 10000, 100000 элементов.

5\. \*\*График\*\* зависимости времени от размера списка.



\## Анализ сложности



\### Временная сложность: O(n)



\- \*\*Лучший случай:\*\* O(1) — элемент первый.

\- \*\*Средний случай:\*\* O(n/2) ≈ O(n).

\- \*\*Худший случай:\*\* O(n) — элемент последний или отсутствует.



\### Пространственная сложность: O(1)



Алгоритм использует только счётчик `i` — дополнительная память не выделяется.
